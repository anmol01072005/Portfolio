## 📌 Overview

A **personal portfolio website** showcasing projects, skills, and professional background. Built with clean HTML, CSS, and JavaScript — designed to make a strong first impression with a modern and responsive layout.

---

## ✨ Sections

- 🙋 **Hero / About** — Introduction, photo, and headline statement
- 🛠️ **Skills** — Tech stack icons and proficiency display
- 📂 **Projects** — Cards showcasing key projects with links
- 📬 **Contact** — Email / social links for outreach

---

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Semantic structure |
| CSS3 | Styling, animations, responsive layout |
| JavaScript | Interactive elements, smooth scroll |
